# Worst Superpower

One line, at most 140 characters, inventing the most useless superpower imaginable — entered in the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on make.fun, where a judge model ranks the field two entries at a time and the single winner takes the $2 pool.

## The entry

> I can stop any baby crying — but only by crying louder, and the baby has filed a complaint.

91 characters. The power is stopping a baby crying with a catch that makes it worse: the only method is crying louder than the baby — and the baby has filed a complaint.

## How to run

```sh
python3 main.py
```

`main.py` (standard library only) validates the line against the competition gate — 1–140 characters, a single line, no leading or trailing whitespace — then writes it to `/output/entry.txt` with mode `0644`.
